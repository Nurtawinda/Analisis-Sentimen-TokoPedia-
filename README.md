**SENTIMENT ANALYSIS TOKOPEDIA**

Deskripsi Project
Project ini bertujuan untuk menganalisis sentimen pengguna terhadap aplikasi Tokopedia berdasarkan ulasan yang diberikan di platform digital. Analisis dilakukan untuk memahami persepsi pengguna serta mengidentifikasi tingkat kepuasan pengguna terhadap layanan aplikasi.

Hasil analisis menunjukkan bahwa sebagian besar ulasan pengguna didominasi oleh sentimen negatif, yang mencerminkan pengalaman pengguna yang kurang baik terhadap aplikasi Tokopedia.

Tujuan
- Mengklasifikasikan ulasan pengguna ke dalam kategori positif, negatif, dan netral
- Menganalisis distribusi sentimen pengguna
- Membandingkan performa model deep learning dan beberapa model machine learning dalam klasifikasi sentimen

Dataset dapat diakses melalui:
([ulasan_tokped.csv](https://drive.google.com/file/d/1HJNZWDmMtI6Ng-ojX9TVhifF7p7imPAF/view?usp=sharing))

Tools dan Teknologi
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Matplotlib / Seaborn

Proses Analisis
1. Data Collection (pengumpulan data ulasan)
2. Data Preprocessing (cleaning, case folding, tokenizing, stopword removal)
3. Pemodelan Deep Learning
4. Feature Extraction menggunakan TF-IDF
5. Pemodelan machine learning
6. Evaluasi performa model

Model yang Digunakan
- Recurrent Neural Network (RNN)
- Random Forest
- Logistic Regression
- Decision Tree

Hasil dan Insight
- Mayoritas ulasan pengguna menunjukkan sentimen negatif
- Hasil akurasi yang diperoleh dari pelatihan menggunakan RNN adalah 85,69%
- Model Random Forest menghasilkan akurasi pelatihan 98% dan akurasi testing 90%
- Model Logistic Regression menghasilkan akurasi pelatihan 94% dan akurasi testing 93%
- Model Decision Tree menghasilkan akurasi pelatihan 94% dan akurasi testing 93%

Kesimpulan
Analisis sentimen dapat membantu memahami opini pengguna terhadap aplikasi Tokopedia dan mendukung evaluasi layanan berbasis data.
